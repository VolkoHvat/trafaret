# AGENTS.md — «Трафарет» (команда «Кир»)

Постоянный рабочий контур Kimi Code для проекта «Трафарет». Этот файл обязателен
к выполнению в каждой сессии Kimi Code.

## Проект

Тату-редактор лайнворка: лучший инструмент для tattoo linework. НЕ копировать
подходы из animation/3D/comics редакторов. Ориентиры по движкам см. в
`docs/ENGINE_COMPARISON.md`.

Стек: React 19 + TypeScript + Vite + PWA, Electron (desktop), Capacitor (Android),
Vitest, ESLint, Tailwind, perfect-freehand.

## Источник истины и порядок работы

- GitHub `main` — единственный источник истины.
- Любые новые код, тесты, config или docs-правки выполняются **только через
  Kimi Code**; обход (ручные правки мимо агента) запрещён.
- Проект не конвертировать в другой стек и не создавать вторую proprietary
  копию.
- Работа малыми шагами: маленькое изменение → тест → ревью → коммит.
- Irreversible/destructive действия (удаление данных, force-push, сброс
  истории, перезапись ветки и т.п.) — только с явным согласием пользователя.

## Секреты и диагностика

- Секреты, credentials, keystore, private keys не читать в проект, не
  логировать, не коммитить. При обнаружении случайно попавших секретов —
  сообщить, не коммитить.
- Диагностика процессов только без command lines (например, `ps -o pid,comm`
  без `args`), чтобы не светить секреты в cmdline.

## Обязательные проверки перед завершением любой задачи

Выполнять по порядку:

1. `npm test`
2. `npm run lint`
3. `npm run build`
4. `npm run desktop:typecheck`

Затем — релевантные существующие audit/regression-скрипты:

- `npm run audit:runtime` — runtime-аудит.
- `npm run audit:electron` — аудит Electron-обвязки.
- `npm run audit:production` — продакшн-регрессия.
- `npm run audit:strictmode` — StrictMode-регрессия.
- `node scripts/advanced-regression.mjs` — расширенная регрессия.
- `node scripts/media-regression.mjs` — регрессия медиа.
- `npm run audit:void-sandbox` — песочница двух режимов энергии ввода.

Выбирать те, что относятся к затронутой области изменения.

## Дисциплина проверок

- Не ослаблять assertions и thresholds, чтобы «пройти» проверку.
- Статус PASS только при реальном доказательстве прогоном.
- Если что-то не проверено — явно помечать NOT_TESTED.

## Архитектурные инварианты (не нарушать)

- Единый формат документа `.tattoo.json` и миграции схемы.
- Canvas и SVG рендер идентичны (Canvas/SVG parity).
- Undo + redo с общим memory budget.
- Все transform/bounds вычисляются из одного модуля geometry.
- Offline-first.
- Конфликты (синхронизация) решает пользователь.
- Токены — только в памяти / native secure storage.
- В Electron сохранять `contextIsolation` и `sandbox` (preload CJS, минимальный
  IPC-поверхность).
- Ассеты runtime — локальные (без внешних CDN на горячем пути).

## Оптимизации

- Перед любой оптимизацией — профиль (замеры), не по догадке.
- Не внедрять tiles / dirty rects / binary snapshots без доказательства
  профилем, что текущего подхода недостаточно.

## Модульность

Не дробить код на shallow helpers. Глубокие модули — history, geometry,
stroke-session, compositor — выделять только отдельными проверенными
изменениями (шаг → тест → ревью → коммит на каждый).

## Первая вертикаль v2 — фактический вход `/`

`src/main.tsx` запускает `src/components/DensityCanvas.tsx`, не `App.tsx`. Первый вход — чистый лист и рабочая кисть; ранее сохранённое поле выбранного размера восстанавливается. Для старых разреженных тайлов 384×240 сохранять базу A/B. Пересечения A/B доступны в «Сцена и история». Бумага — только экранный фильтр, не источник для PNG, печати или снимков. `src/lib/density-transfer.ts` — поле фиксированного размера, локальные переносы реальной массы с фиксированной энергией, пространственный остаток шага и две проекции. Не подмешивать alpha-след, perfect-freehand, время или давление. Очередь до 2048 samples: обработка по RAF (до 128 точек, до 64 импульсов с переносом незавершённого сегмента); при переполнении прореживание, не отмена. Круг, направленное перо 45° и обратное заполнение (только интервалы samples, без wall clock). Оба размера (384×240 и 2048²) работают на одном ядре, размеры ограничены allowlist. Для истории и автосохранения захватываются тайлы 32×32; общий лимит Undo/Redo — 12 изменений и 32 МиБ полезных данных; ветвление очищает Redo. `src/lib/field-document.ts` задаёт отдельный `.tfd` v2, без v1-миграции. Только завершённое поле пишется в отдельный IndexedDB (`src/lib/field-workspace-store.ts`); не записывать активные/отменённые штрихи или историю. Для каждого размера читать базу, тайлы, метаданные и ревизию в одной транзакции. В readwrite сверять ожидаемую ревизию и записывать пакет с новой ревизией атомарно; отсутствие ключа ревизии означает 0. При конфликте не перебазировать автоматически: аварийный `.tfw` из памяти, актуальная версия только с подтверждением. После build запускать `node scripts/performance/field-workspace.mjs` и `node scripts/performance/field-conflict.mjs`. Экспорты: проверяемый lossless `.tfd` и PNG текущей проекции.

PNG/JPEG reference хранится отдельно в локальном workspace и никогда не включается в новые `.tfw`, `.tfd`, PNG или FieldPrint. Raster preview — ограниченный офлайн-анализ RGBA, не векторизация; commit через PathInput/Transfer одной записью истории. Отчёт отдельным JSON только opt-in.

Диагностика последнего жеста строго opt-in и только в памяти. `src/lib/gesture-diagnostic.ts` замораживает исходные тайлы до изменения, включая область максимальной альтернативной кисти; `src/lib/gesture-worker.ts` выполняет сравнения на отдельном поле. Не записывать replay в history/IndexedDB; pressure остаётся метаданными. Неполный/отменённый ввод не сертифицировать как точный повтор. `node scripts/performance/density-2048.mjs` проверяет повтор через синтетический CDP pen, не заменяет физическую проверку.

Срез (`DensitySection.tsx`, `density-section.ts`) читает только замороженные тайлы base/result последнего записанного штриха. Не подставлять живое поле или ρ=1 вместо отсутствующих данных. Выбор отрезка обрабатывает отдельный SVG поверх canvas, не путь рисования. Максимум 512 выборок, в графике пропуски; сценарий пересечения включён в `density-2048.mjs`.

После build: `node scripts/performance/density-browser.mjs` проверяет `/` и реальные пиксели на временном сервере. Аудиты старой студии не служат E2E нового интерфейса. Старая схема `.tattoo.json`, SVG и синхронизация относятся к сохранённой студии; в вертикаль они не перенесены. Не переписывать остальные подсистемы под видом совместимости.

`FieldPrint.tsx` получает только canvas проекции (без подложки) и контролируемую ширину в мм. Для A4 проверяется вместимость без автоподгонки. Отдельная проверка компонента: `node scripts/performance/field-print.mjs [путь.pdf]` (Chromium; измеряет print-layout и размер страницы PDF). Физическую точность подтверждать отдельно на бумаге при 100% по внешним краям линейки 50 мм; PDF не проверяет драйвер и принтер.

`/?field=2048` открывает основную студию 2048² (чистый первый документ); вход через кнопку «Основная студия» на прежней странице 384×240. `surface=1` — второй вид документа выбранного размера: тот же Float64Array, TileHistory и CAS workspace, без перезагрузки. Атлас не ресемплирует документ 2048². `Workspace.surfaceBody` содержит принятые мерки в см и необязательный `preset` (`male`/`female`); без пресета сохраняются исходные мерки. «Тело» (по умолчанию) строит по ним связанную оболочку с буфером глубины, «Схема» оставляет прежние сегменты. Переключатель не записывается в документ. Проверка обоих видов и ракурсов в Edge: `node scripts/performance/surface-anatomy.mjs <outDir> <pngDir>`. Обе условные формы используют те же UV-острова; смена пресета не заменяет поле и пигмент. Проверка с парными PNG: `node scripts/performance/surface-body-presets.mjs <outDir> <pngDir>`. Как и раньше, `.tfw` без этого ключа по-прежнему читается. Старые `.tfs` и `trafaret-surface-checkpoint` открываются по выбору пользователя, без записи в старый checkpoint. Не сохранять жесты в процессе, историю, камеру или маску зоны. Production E2E: `node scripts/performance/shared-field.mjs <outDir>`.

На обоих размерах line/fill — каналы `PigmentField`, общие для поля и Surface. Цветной штрих фиксирует rho и PigmentDelta одной операцией; preview заливки не меняет документ. `.tfw` включает полный снимок; в IndexedDB при жестах, Undo и Redo пишутся только изменённые тайлы с общей CAS-ревизией. `.tfs` доступен только для 384×240 и не содержит пигмент. Stencil читает только rho. Проверка кадров: `node scripts/performance/pigment-frames.mjs <outDir> [2048]`. Режим кисти «Без буфера» (bufferMode=off) не создаёт compression ring и не изменяет rho существующего поля; line/pigment записывается отдельно в core при tone, в stencil не виден. Режим сохраняется в .tfw, undo/redo и CAS; Surface использует тот же режим. Это не pure pigment/stencil mode и не обещает stencil-линию без изменения rho.

Опциональный режим «Смешение пигментов» в палитре поля и Surface меняет только пигмент. До подтверждения линии и заливки показывается составной кадр. Масса и три коэффициента рассеяния по 16 бит хранятся в плоскостях mixMR/mixGB, граница цветной линии — в mixLine. Они используют обычные дельты истории и CAS тайлов, входят в .tfw и не участвуют в stencil. Проверка по production: `node scripts/performance/mix-production.mjs <outDir> <report.json>` с `CHROME_PATH` для Edge.

«Примерить» на обоих размерах — отдельный просмотр текущего canvas без подложки. Ширина берётся из `Workspace.widthMm` (как у FieldPrint), высота пропорциональна размерам документа. Локальные мерки в мм, размещение и камера живут только до выхода из просмотра. Нет новых ключей в файлах, IndexedDB или записях истории. Проверка: `node scripts/performance/local-surface.mjs dist <screenshot.png>`.

Кисть «Вещество поля» использует тот же пространственный импульс, переносит целочисленные массу и три полосы рассеяния mixMR/mixGB из ядра в доступное кольцо. Без подачи баланс точный, при насыщении остаток остаётся у донора. Запись единая с rho после завершения жеста; legacy line/fill и stencil не перемещают смесь. Fine-line — оценка на пробе с учётом шага листа либо локальной UV-метрики; зум не увеличивает разрешение атласа.

## Сохранённый контур редактора 1.3 и старых экспериментов

P0 и P1 (`history`, `geometry`, `stroke-session`, `compositor`) завершены с
regression tests. Кривые Безье, управляющие ручки,
добавление/удаление узлов, профиль толщины, групповые трансформации, flattened
PSD, ABR brush presets, sRGB/Display P3 и декларативный plugin API реализованы.
RDP simplification векторных путей реализован с допуском 0,5–12 px и точным Undo/Redo.
Дублирование выбранных векторных объектов реализовано с новыми ID и общей историей.
Переименование слоёв сохраняется в проекте и после перезагрузки.
Delete удаляет всю Shift-выбранную группу объектов одной записью истории.
Статус 1.3.0: стабильное функциональное обновление специализированного редактора,
а не подтверждение финального уровня. Следующий этап: v2.0 с профессиональными
доработками, без заявления паритета с CSP/Krita без измерений.

Экспериментальная проба нового ядра: `src/lib/void-field.ts` и
`src/lib/void-language.ts` реализуют плотность/разрежённость, компактный буфер
сжатия и его ширину, обратную инерцию, условную энергию кисти, статические
наблюдения, ремоделирование по пользовательским точкам и `refill`.
Команды: `npm run probe:void`, `npm run bench:void`. Это изолированный исследовательский
код, не текущий движок редактора. Полная проекция имеет стоимость O(N × Q): перед
интеграцией нужны пространственное ограничение вкладов и профилирование.

`void-sandbox.html` и `src/void-sandbox.ts` — изолированная песочница стандартного
и измеренного энергетического ввода, пяти кистей с E = const и фигур через события
динамической кривой, не функция основного редактора. Авторские сцены: виверна и
курсив Silentium с SVG-выводом. Палитра приложения и песочницы: угольная/пепельная
с магматическим акцентом.

Композиция в DensityCanvas открывается кнопкой «Композиция» и работает read-only на снимке текущей проекции: flat-проверка, отметка внимания, условная спина с непечатаемыми направляющими и рукав с тремя ракурсами, швом, смещением и реальными мерками. Это не эстетический балл и не анатомическая модель; preview-размер не меняет размер на коже. Не читать reference и не менять rho/pigment/history/.tfw. Проверка композиции в `scripts/performance/composition-review.mjs` принадлежит интегратору и не изменяется этим контуром.

Новые функции выполнять отдельными проверенными изменениями по правилам выше.
