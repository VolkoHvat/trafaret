# Маркетинговый пакет «Трафарет» v1.0

Практичные материалы для команды «Кир»: позиционирование, тексты для публикаций и ответы на вопросы. Центральная идея: **от первой линии до трафарета — инструмент не мешает рисовать**; самостоятельность и локальность.

## Позиционирование

**Трафарет — бесплатная автономная студия тату-линворка.** Всё, что нужно для эскиза, который станет трафаретом: кисти линворка, слои, работа со сканами, анализ эскиза, экспорт и печать — на устройстве пользователя, без сети, аккаунтов и подписки.

Не позиционируем как «замену Clip Studio Paint» и не обещаем «лучше CSP». Трафарет — узкий и честный инструмент под задачу тату-мастера, а не универсальная студия.

## Аудитория

- Тату-мастера, рисующие эскизы на планшете (Android) и ПК (Windows).
- Ученики и начинающие мастера, которым важен доступный и бесплатный инструмент.
- Художники линворка, dotwork, blackwork — кому нужны узкоспециализированные кисти и трафаретный экспорт.

## Ключевые преимущества

1. **Полностью локально и бесплатно.** Рисование, анализ, экспорт и автосохранение работают без сети и аккаунтов. Облако — только опциональная синхронизация Google Drive по решению пользователя.
2. **Инструмент под линворк, а не подо всё.** 7 специализированных кистей (Fineline, Traditional, Blackwork, Dotwork, Whip shade, Sketch, Soft shade), давление пера, режим «только перо» против случайных касаний ладонью.
3. **От эскиза до трафарета в одном окне.** Сканы с порогом и контрастом, режим трафарета, локальный анализ (лишние узлы, мелкие детали, композиция, выход за край), экспорт PNG с DPI, SVG и печать в реальных миллиметрах.
4. **Прозрачность и контроль.** Исходный код опубликован на GitHub, конфликты синхронизации решает пользователь, честный список того, что не проверено.

## Ответы на возражения

**«Есть же CSP / Procreate»**
Трафарет не претендует на их место. Это узкий инструмент под линворк и трафареты: свои кисти, режим трафарета, анализ эскиза и печать в мм. Бесплатно и локально — можно держать рядом с основной студией.

**«Нет кодовой подписи Windows — небезопасно»**
Подпись отсутствует по понятной причине (коммерческая подпись платная). Исходники и хеши готовых файлов опубликованы в Release Notes. SmartScreen покажет предупреждение — это ожидаемо.

**«APK из интернета — подозрительно»**
Верно, осторожность оправдана. Проверьте SHA-256 из Release Notes и соберите APK сами из исходников командой `npm run android:apk`.

**«А если пропадёт интернет?»**
Ничего. Вся работа локальна: рисование, слои, экспорт, автосохранение. Сеть нужна только для опциональной синхронизации.

**«Кто владелец моих эскизов?»**
Только вы. Проекты хранятся на устройстве; в Google Drive отправляется лишь то, что вы синхронизируете.

**«На планшете будет тормозить?»**
Производительность оптимизирована: по замерам команды память при большом документе сокращена на ~28–32% относительно исходной реализации, заливка ускорена в 1,5 раза. На слабом железе есть встроенная диагностика API, покажет, что поддерживается браузером.

## Честные ограничения

- Нет коммерческой кодовой подписи Windows — SmartScreen предупредит.
- Не тестировались физические Wacom/WinTab/Windows Ink, touchscreen и GPU; диагностика проверяет API браузера, а не железо.
- Не тестировались реальный принтер, реальный Google Drive с учётными данными и установка на физические устройства.
- Синхронизация требует собственный Google Client ID.
- Векторные фигуры — базовые (прямоугольник, эллипс, дуга); нет текстовых слоёв и полноценной типографики.
- Проект молодой: один выпуск, маленькая команда, скорость реакции на баг-репорты ограничена.

Не обещаем «лучше CSP», не публикуем выдуманные цифры пользователей и отзывы, не используем скриншоты, которых нет.
