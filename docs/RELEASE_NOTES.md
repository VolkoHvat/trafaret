## Функции

- **Кисти линворка**: Fineline, Traditional, Blackwork, Dotwork, Whip shade, Sketch, Soft shade; настройка размера, непрозрачности, сужения, стабилизации, streamline, затухания, кривой давления (soft/linear/firm), числа проходов, джиттера; пользовательские пресеты.
- **Перо и касания**: давление через Pointer Events, режим «только перо» (palm rejection), pinch-to-zoom двумя пальцами.
- **Инструменты**: объект, кисть, ластик, линия, фигуры (прямоугольник, эллипс, дуга), перо, заливка, область, лассо, панорама, пипетка.
- **Слои**: растровые, векторные, image-слои; маски, обрезка по нижнему слою, векторные клипы; видимость, блокировка, непрозрачность, наложение.
- **Выделения**: прямоугольник, эллипс, лассо, инверсия; заливка и рисование внутри выделения.
- **Симметрия**: вертикальная и радиальная (настраиваемое число сегментов); направляющие-круги и эллипсы.
- **Сканы и трафарет**: image-слои с фильтрами (grayscale, контраст, порог, инверсия); режим трафарета; экспорт «Трафарет PNG».
- **Локальный анализ эскиза** (без сети и AI): избыточные узлы, дубликаты, мелкие элементы, выход за край холста; плотность, дисбаланс и центр масс композиции, безопасные поля. Рекомендации, а не вердикт.
- **Экспорт**: PNG с записанным DPI (чанк pHYs), SVG из векторных слоёв, печать с размерами в миллиметрах.
- **Проекты**: `.tattoo.json`, автосохранение в IndexedDB, undo/redo.
- **Offline/PWA**: работа без сети, установка из браузера.
- **Диагностика**: встроенные локальные проверки API-слоя (Canvas 2D, pointer-события, маски, выделения).
- **Синхронизация**: Google Drive (ручная/автоматическая), при конфликте версий выбор делает пользователь.

## Оптимизации

- Память при работе с большим документом: prefill 800 МБ против 1107 МБ baseline (**−27,7%**), postfill 897 МБ против 1312 МБ (**−31,7%**).
- Заливка: 732,31 мс против 1135,44 мс baseline (в **1,55 раза** быстрее).
- Ленивое выделение backing store у временных canvas; освобождение памяти при смене документа.

## Проверки

- Unit-тесты: **96/96 PASS**; lint, typecheck, build: **PASS**.
- Production-регрессия: **13/13** сценариев.
- Диагностика API: **10/10** в режимах default и disable-gpu.
- Electron: **PASS** в режимах default и disable-gpu.
- Pen / palm / pinch: **PASS**.
- Рендеринг: pixel-identical между baseline и current, GPU и no-GPU.

## Что не проверено (NOT_TESTED)

- Реальные Wacom / WinTab / Windows Ink.
- Физический touchscreen / GPU / дигитайзер устройств.
- Принтер и бумага.
- Реальный Google Drive с учётными данными.
- Физические устройства Windows и Android.
- Реальный запуск Windows-установщика и установка APK.

Диагностика проверяет API-слой браузера; это не сертификация драйверов и не проверка оборудования.
