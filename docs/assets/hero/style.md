# Style Plan — «Живая линия»

**Name:** Живая линия (Living Line)
**Keywords:** чернила, бумага, пойманное движение

**Style description:**
Авторский tattoo flash key visual, рисованный одной «живой» линией на плотной бумаге.
Тонкий fineline-контур держит силуэт орнаментальной моли, сильное черное тело даёт
композиции вес, а несколько точек dotwork и оборванные штрихи у крыла фиксируют
движение, остановленное в неподвижности. Никакой растрированной фактуры — только
векторный контур, пустота и асимметрия.

**Font plan:**
- Noto Serif Display — крупный авторский знак «КИР» (display, через Google Fonts).
- Manrope — короткое слово-метка «ТРАФАРЕТ» в технической строке.
- IBM Plex Mono — техническая часть строки «/ LINE STUDY 01» (оба через Google Fonts).

**Color scheme:**
- Ink `#0a0a0a` — весь линейный рисунок и текст (чернила).
- Paper `#fafafa` — фон страницы (бумага).
- Hairline `#e5e5e5` — едва заметные вспомогательные плоскости, глубина бумаги.
Палитра строго трёхцветная, приоритет у чернил на бумаге; серый — только фоновый тон.

**Layout plan:**
Формат 3:4, 960×1280. Асимметрия: мола смещена вправо от вертикальной оси,
крупное переднее крыло уходит в правый верхний квадрант и частично покидает
привычный центр композиции. Левый нижний квадрант оставлен пустым: там крупный
знак «КИР», в левом верхнем углу — маленькая техническая строка. Большие поля
пустоты сверху и снизу держат воздух. Ни одного элемента за пределами страницы.

**Core visual element requirements:**
- Мола строится только из native editable shape (custom path / ellipse) и line —
  никаких растровых изображений, image generation и внешних assets.
- Переднее правое крыло: большой контур, тонкий fineline (≈1–1.2 px), внутренний
  контур-орнамент; левое крыло меньше и ниже (асимметрия).
- Тело моли: сильный силуэт, заливка чернилами `#0a0a0a`, голова — сплошной
  эллипс, усики — тонкие плавные линии.
- Dotwork очень сдержанный: 8–9 точек, идущих нарастающим/убывающим ритмом
  вдоль кромок крыльев.
- Движение: 2–3 оборванных легких штриха за правым крылом, полупрозрачные.
- Контраст: чернила на бумаге обеспечивают высокий контраст во всех узлах.
- Без UI-элементов, без скриншотов, без повторяющихся карточек и декоративного избытка.
